# Данные → выводы

Небольшое веб-приложение для анализа CSV и Excel. Пользователь загружает таблицу,
задаёт вопрос и получает метрики, наблюдения и замечания по качеству данных.
Доступны бесплатный режим Groq для небольших таблиц и режим OpenAI для больших
файлов и графиков.

## Как работает агент

1. Streamlit принимает исходный файл и показывает его предпросмотр.
2. В режиме **Groq** приложение передаёт *всю* небольшую CSV-таблицу в запросе.
   Excel преобразуется в CSV-блоки по листам без вычисления метрик. Модель
   `openai/gpt-oss-120b` вызывает встроенный `code_interpreter` Groq.
3. В режиме **OpenAI** приложение загружает полный исходный файл через Files API.
   Responses API передаёт его в контейнер `code_interpreter`.
4. В обоих режимах `tool_choice="required"` требует вызова Python-инструмента.
   Приложение проверяет факт выполнения и показывает код вместе с выводами.
5. В режиме OpenAI агент может создать PNG-график; приложение извлекает его из
   контейнера и показывает на странице.

Метрики **не вычисляются приложением заранее и не подставляются в промпт**. Код
предпросмотра не участвует в аналитическом ответе.

## Запуск

Требуются Python 3.10+ и API-ключ выбранного провайдера.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Для бесплатного режима создайте ключ в [Groq Console](https://console.groq.com/keys)
и укажите `GROQ_API_KEY` в `.env`. Регистрация ключа происходит в вашем аккаунте;
его нельзя получить из чужого аккаунта или вставить в открытый код. Базовый
бесплатный лимит модели GPT-OSS — 8 000 токенов в минуту, поэтому приложение
принимает в этом режиме не более 10 КБ текстового представления таблицы.
Файл не обрезается: если он больше, появится сообщение об ошибке. Режим Groq
возвращает вычисленные метрики и выводы; загрузка PNG-графика из встроенного
инструмента в текущей интеграции не предусмотрена.

Если у вас есть платный ключ OpenAI, укажите `OPENAI_API_KEY` в `.env` и выберите
OpenAI на странице. По умолчанию используется модель `gpt-4.1`.

```bash
streamlit run app.py
```

Откройте адрес, который выдаст Streamlit (обычно `http://localhost:8501`). Для
проверки можно загрузить [sample_data/sales.csv](sample_data/sales.csv) и спросить:
«Как менялась выручка по месяцам и регионам?». Приложение принимает CSV и `.xlsx`
до 15 МБ для OpenAI; для Groq действует меньший лимит выше. Данные отправляются
выбранному API. Не загружайте чувствительные данные без разрешения.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q app.py analysis_agent.py groq_agent.py
```

Тесты проверяют передачу всей таблицы агенту, обязательный вызов Python,
загрузку графика OpenAI и отказ от ответа без вызова инструмента. Полный
API-сценарий нужно проверить с действующим ключом.

## Развёртывание и сдача

Для публичного доступа удобно использовать Streamlit Community Cloud: загрузите
репозиторий на GitHub, укажите `app.py` как главный файл и добавьте
`GROQ_API_KEY` (или `OPENAI_API_KEY`) в Secrets приложения. Ключ нельзя коммитить
в репозиторий.
После развёртывания приложите к сдаче URL приложения и URL GitHub-репозитория.
Если публичное размещение недоступно, приложите к отчёту скриншоты результата
реального запуска с ключом, включая развёрнутый блок «Как агент считал результат».
