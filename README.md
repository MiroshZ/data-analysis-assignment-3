# Данные → выводы

Учебное веб-приложение для анализа таблиц CSV и Excel. Пользователь загружает файл, задаёт вопрос и получает сводные показатели, выводы и проверку качества данных. Расчёты выполняет Python-инструмент языковой модели; выполненный код можно посмотреть в интерфейсе в разделе **«Как агент считал результат»**.

Для демонстрации в репозитории приложен файл [`sample_data/sales.csv`](sample_data/sales.csv).

## Запуск

```bash
streamlit run app.py
```

В интерфейсе загрузите таблицу, введите вопрос и нажмите **«Проанализировать»**. Результат можно скачать в формате Markdown.

## Файлы проекта

- `app.py` — интерфейс приложения.
- `analysis_agent.py`, `groq_agent.py` — обработка данных и вызов Code Interpreter.
- `sample_data/sales.csv` — пример данных.
- `tests/` — автоматические проверки.
